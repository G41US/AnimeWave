# AnimeWave

Anime-only Android app starter for Android phones and Android TV / Airtel Smart Box devices.

## Features
- Kotlin + Jetpack Compose dark UI
- Home, Discover, search by title or genre, and My List
- Detail page and Watch action for authorized HTTPS URLs
- Android TV launcher support
- Demo catalog so the interface can be explored before a provider is connected

## Current status
This is a **starter UI**, not yet a complete streaming service or compiled APK. The included catalog is fictional demo content. Real anime metadata, artwork, episode listings and playback require a licensed catalog/streaming provider or content you own or are authorized to distribute.

## Build
Requirements: Android Studio, JDK 17, Android SDK Platform 35.

1. Open the repository folder in Android Studio.
2. Allow Gradle sync to finish.
3. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

For command line builds, use `gradle assembleDebug` from the project root after installing a compatible Gradle version. For repeatable builds, add the Gradle wrapper files generated by Android Studio.

## Add an authorized stream
Add a `watchUrl` to an `Anime` item in `app/src/main/java/com/animewave/app/MainActivity.kt`. The current Watch action opens HTTPS links externally. For in-app playback, implement a Media3 ExoPlayer screen and confirm the stream provider permits playback inside this app.

Do not embed provider API secrets in the APK. Use a backend for private credentials and respect provider authentication, subscription, territory, DRM and terms.
