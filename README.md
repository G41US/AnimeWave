# AnimeWave

Anime-only Android app starter for Android phones and Android TV / Airtel Smart Box devices.

## Features
- Real anime catalog from the free AniList API (no key): trending, airing this season, genres, search, posters and banners
- Detail page with synopsis, score, and **Watch** buttons that open official streaming services (Crunchyroll, Netflix, etc.) and their episode links
- **My List** saved on the device
- Built-in Media3 player for your own videos: pick several episodes (sorted Ep 1, 2 … 10), next/previous buttons, subtitles from matching `.srt`/`.vtt`/`.ass` files or built-in tracks (CC button)
- Play an HTTPS video or HLS (`.m3u8`) link you have permission to play
- Phones (edge-to-edge, rotation-safe, landscape fullscreen player) and Android TV / Airtel box (D-pad focus rings, Back navigation, remote media keys)

## Cloud build
Every push to `main` runs unit tests and builds a debug APK in GitHub Actions. Download it from the run's **AnimeWave-debug-apk** artifact.

## Build
Requirements: Android Studio, JDK 17, Android SDK Platform 35.

1. Open the repository folder in Android Studio.
2. Allow Gradle sync to finish.
3. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

For command line builds, use `gradle assembleDebug` from the project root after installing a compatible Gradle version. For repeatable builds, add the Gradle wrapper files generated by Android Studio.

## Notes
- The app only plays your own files or links you're authorized to use; it does not scrape or host anime.
- Some file managers on Android TV boxes don't include a file picker. Use **Play a stream link** there.
- AniList limits requests per minute; the app debounces search to stay under it.
